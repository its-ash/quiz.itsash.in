## why quiz://

Built for gotchas, not trivia

Production-grade scenarios

Every question is drawn from real bugs, not toy snippets — the kind that survive code review and bite in prod.

Progressive difficulty

Basic recall → edge cases → best-practice judgment calls, ordered so every quiz builds on the last.

Explanations that teach

Collapsed answers explain the mechanism — evaluation order, coercion rules, borrow rules — not just the label.
